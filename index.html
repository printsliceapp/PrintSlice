Before you ask

What is PrintSlice?

A browser-based tool that splits oversized STL models into bed-sized pieces and generates matching connectors so they assemble back into the original shape.

What file types are supported?

STL files, both binary and ASCII, for input — and binary STL for the split output pieces, the standard format every slicer accepts.

How does automatic splitting work?

You set your printer's bed size and a safety margin; PrintSlice computes watertight cuts through the model so every resulting piece fits within that volume.

How do the connectors work?

Every connector pair — the tab and its matching socket — is generated from one shared definition using real solid geometry, with a small configurable clearance built in.

Does PrintSlice work with any 3D printer?

Yes — the exported pieces are standard STL files, compatible with any slicer or printer you already use.

Do I need to install anything?

No. Splitting, connector generation, and the 3D preview all run in your browser — nothing to install, and your model never leaves your computer.

How does pricing work?

One plan at $8.99/month, cancel anytime — no tiers or feature gating. See the full FAQ for billing details.

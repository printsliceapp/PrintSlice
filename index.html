What file types are supported?

STL files, both binary and ASCII, for input — and binary STL for the split output pieces, the standard format every slicer accepts.

Does PrintSlice work with any 3D printer?

Yes — the exported pieces are standard STL files, compatible with any slicer or printer you already use.

Do I need to install anything?

No. Splitting, connector generation, and the 3D preview all run in your browser — nothing to install, and your model never leaves your computer.
